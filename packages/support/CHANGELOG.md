# Changelog

## 0.10.0 – 2026-11-12

### Changed

- Released from the [denosyscore/framework](https://github.com/denosyscore/framework)
  monorepo, where this package now lives under `packages/support`. All DenoSys
  packages share one version line, so the version moves from v0.1.0 to
  0.10.0. There are no API changes in this release.
- Requirements on other DenoSys packages are `^0.10`.

## Unreleased (proposed 0.1.0)

- Add the `Denosys\Support\Collection` package API backed by Illuminate
  Collections.
- Add a semantic-tag release workflow and document the initial release steps.
